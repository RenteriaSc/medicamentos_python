  SECCIÓN 1 — IMPORTACIONES
  Las herramientas que el programa necesita para funcionar
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  import json
  ──────────────────────────────────────────────────────────────────────────────
  Le dice a Python: "quiero usar herramientas para leer y escribir
  archivos .json". Sin esta línea no podríamos guardar ni cargar datos.
  Un archivo JSON es como una libreta estructurada donde guardamos
  información en forma de texto organizado.

  import os
  ──────────────────────────────────────────────────────────────────────────────
  Importa herramientas del sistema operativo. Se usa para dos cosas:
    1. Limpiar la pantalla de la terminal.
    2. Verificar si un archivo existe en el disco duro.
  "os" viene de "Operating System" (sistema operativo).

  import sys
  ──────────────────────────────────────────────────────────────────────────────
  Herramientas del propio Python. Se usa para:
    1. Verificar qué versión de Python está corriendo.
    2. Cerrar el programa de forma controlada con sys.exit().
  "sys" viene de "system" (sistema).

  import time
  ──────────────────────────────────────────────────────────────────────────────
  Herramientas para manejar el tiempo. Se usa principalmente para
  time.sleep(1), que hace que el programa "duerma" (pause) por
  la cantidad de segundos indicada. Ejemplo: time.sleep(1.2)
  pausa el programa 1.2 segundos.

  import threading
  ──────────────────────────────────────────────────────────────────────────────
  Esta es la más avanzada. Permite que el programa ejecute dos tareas
  al mismo tiempo (en paralelo). Sin threading, el menú se bloquearía
  mientras espera que llegue la hora de un recordatorio.
  Con threading, el menú funciona normalmente Y los recordatorios
  se revisan en segundo plano al mismo tiempo.

  import importlib.util
  ──────────────────────────────────────────────────────────────────────────────
  Herramienta para verificar si una librería está instalada,
  sin necesidad de importarla todavía. Esto es útil para librerías
  opcionales: si no están instaladas, el programa sigue funcionando.

  from datetime import datetime, timedelta
  ──────────────────────────────────────────────────────────────────────────────
  De la librería "datetime" importa DOS cosas específicas:

    datetime → para obtener la hora actual, y para convertir texto
               a objetos de hora y viceversa.
               Ejemplo: datetime.now() devuelve la hora exacta ahora.

    timedelta → representa una "duración" que se puede sumar a una hora.
                Ejemplo: si tienes las 08:00 y sumas timedelta(hours=8),
                obtienes las 16:00.

  La diferencia con "import datetime" (sin el from) es que así podemos
  escribir directamente "datetime.now()" en lugar de "datetime.datetime.now()".

  hilo_recordatorio = None
  ──────────────────────────────────────────────────────────────────────────────
  Aquí se guardará el "hilo" (proceso en segundo plano) que
  revisa los recordatorios. Empieza en None porque todavía

  recordatorio_activo = False
  ──────────────────────────────────────────────────────────────────────────────
  Un interruptor booleano (solo puede ser True o False).

  def limpiar_pantalla():

      os.system("cls" if os.name == "nt" else "clear")
      ────────────────────────────────────────────────────────────────────────
      Detecta el sistema operativo y ejecuta el comando correcto.

      os.name == "nt"  →  pregunta: ¿estoy en Windows?
                          ("nt" es el nombre interno de Windows en Python)

      Si la respuesta es SÍ → ejecuta "cls"   (comando de Windows)
      Si la respuesta es NO → ejecuta "clear" (comando de Mac/Linux)

      Esto se llama OPERADOR TERNARIO: es un if-else en una sola línea.
      La sintaxis es:  valor_si_verdadero  if  condicion  else  valor_si_falso


  def separador(caracter="─", ancho=52):
  ──────────────────────────────────────────────────────────────────────────────
  Función con dos parámetros que tienen VALORES POR DEFECTO.
  Si se llama como separador() sin argumentos, usa "─" y 52.
  Si se llama como separador("═") usa "═" y 52.
  Si se llama como separador("★", 50) usa "★" y 50.
  Esto se llama PARÁMETROS OPCIONALES.

      print(caracter * ancho)
      ────────────────────────────────────────────────────────────────────────
      En Python, multiplicar un string por un número lo repite.
      "─" * 52  produce:  ────────────────────────────────────────────────────
      "═" * 52  produce:  ════════════════════════════════════════════════════
      "★" * 10  produce:  ★★★★★★★★★★


  def pausar():

      input("\n  Presione ENTER para continuar...")

      limpiar_pantalla()

      separador("═")
      print()
      ────────────────────────────────────────────────────────────────────────

  def cargar_usuarios() -> dict:
  ──────────────────────────────────────────────────────────────────────────────
  El "-> dict" indica que esta función DEVUELVE un diccionario.
  Un diccionario en Python es como una tabla de dos columnas:
  clave → valor. Ejemplo: {"sebas": {"contrasena": "1234"}}.

      if os.path.exists(ARCHIVO_USUARIOS):
      ────────────────────────────────────────────────────────────────────────
      Pregunta: ¿existe el archivo usuarios.json en el disco?
      os.path.exists() devuelve True si el archivo existe, False si no.

          try:
          ──────────────────────────────────────────────────────────────────
          Inicia un bloque "intenta hacer esto". Si algo falla dentro,
          salta al bloque except en lugar de explotar el programa.

              with open(ARCHIVO_USUARIOS, "r", encoding="utf-8") as f:
              ────────────────────────────────────────────────────────────
              Abre el archivo para LEER ("r" = read = leer).
              encoding="utf-8" asegura que lea correctamente tildes y ñ.
              "with" garantiza que el archivo se cierre aunque haya errores.
              "as f" le da el nombre "f" al archivo abierto.

                  return json.load(f)
                  ────────────────────────────────────────────────────────
                  json.load(f) lee el archivo JSON y lo convierte
                  automáticamente en un diccionario de Python.
                  return devuelve ese diccionario a quien llamó la función.

          except (json.JSONDecodeError, IOError):
          ──────────────────────────────────────────────────────────────
          Si algo salió mal (archivo dañado o problema de lectura),
          captura el error sin explotar el programa.
          JSONDecodeError = el archivo no tiene formato JSON válido.
          IOError = problema al leer el archivo.

              return {}
              ────────────────────────────────────────────────────────────
              Devuelve un diccionario vacío {} como si no hubiera usuarios.

      return {}
      ────────────────────────────────────────────────────────────────────────
      Si el archivo no existía (el if fue False), también devuelve
      diccionario vacío. Primera vez que se ejecuta el programa.


  def guardar_usuarios(usuarios: dict):

      try:
          with open(ARCHIVO_USUARIOS, "w", encoding="utf-8") as f:
          ────────────────────────────────────────────────────────────────────
          Abre el archivo para ESCRIBIR ("w" = write = escribir).

              json.dump(usuarios, f, ensure_ascii=False, indent=4)

              json.dump convierte el diccionario Python a texto JSON

              ensure_ascii=False → permite guardar tildes y ñ correctamente.
              indent=4 → formatea el JSON con sangría de 4 espacios,
                         haciéndolo legible para humanos.

      except IOError as error:
          print(f"\n  ⚠️  No se pudo guardar usuarios: {error}")
      ────────────────────────────────────────────────────────────────────────
      Si hay problema al escribir (disco lleno, permisos), muestra
      el error pero no explota el programa.


  def usuario_existe(nombre: str) -> bool:
  ──────────────────────────────────────────────────────────────────────────────
  Verifica si ya hay un usuario con ese nombre.
  -> bool indica que devuelve True o False.

      usuarios = cargar_usuarios()
      ────────────────────────────────────────────────────────────────────────
      Llama a la función anterior para obtener todos los usuarios.

      return nombre.lower() in [u.lower() for u in usuarios.keys()]
      ────────────────────────────────────────────────────────────────────────
      Esta línea hace varias cosas al mismo tiempo:

      usuarios.keys()
        → obtiene solo los nombres de usuario (las claves del diccionario).
          Ejemplo: ["sebas", "carlos", "maria"]

      [u.lower() for u in usuarios.keys()]
        → COMPRENSIÓN DE LISTA: convierte todos los nombres a minúsculas.
          Ejemplo: ["sebas", "carlos", "maria"]
          Así comparamos sin importar si escriben "Sebas" o "SEBAS".

      nombre.lower() in [...]
        → pregunta: ¿el nombre (en minúsculas) está en esa lista?
          Devuelve True si existe, False si no.

      return devuelve ese True o False directamente.


  def validar_contrasena(contrasena: str) -> tuple:
  ──────────────────────────────────────────────────────────────────────────────
  -> tuple indica que devuelve una TUPLA (par de valores).
  Una tupla es como una lista pero no se puede modificar.

      if not contrasena:
      ────────────────────────────────────────────────────────────────────────

      return True, ""
      ────────────────────────────────────────────────────────────────────────
      Si pasó todas las validaciones, devuelve True y mensaje vacío.

          Llama a validar_contrasena() que devuelve dos valores.
          Python permite recibir múltiples valores así:
          valida = True o False
          motivo = el mensaje de error (o "" si es válida)

          if not valida:

          ──────────────────────────────────────────────────────────────────

  def validar_hora(hora_texto: str) -> bool:

  def calcular_horarios(hora_inicio: str, frecuencia: int) -> list:
  ──────────────────────────────────────────────────────────────────────────────
  Genera todos los horarios del día automáticamente.
  Ejemplo: inicio="08:00", frecuencia=8 → ["08:00", "16:00", "00:00"]

      horarios    = []          → lista vacía que iremos llenando
      hora_actual = datetime.strptime(hora_inicio, "%H:%M")
      ────────────────────────────────────────────────────────────────────────
      Convierte el texto "08:00" a un objeto de hora para poder
      sumarle horas con timedelta.

      vistos = set()
      ────────────────────────────────────────────────────────────────────────
      Un SET (conjunto) en Python es como una lista pero sin duplicados
      y con búsqueda instantánea. Lo usamos para detectar cuándo
      dimos la vuelta completa (volvimos a la hora inicial).

      while True:
          hora_str = hora_actual.strftime("%H:%M")
          ──────────────────────────────────────────────────────────────────
          .strftime() convierte el objeto de hora de vuelta a texto.
          Ejemplo: el objeto que representa las 16:00 → "16:00".

          if hora_str in vistos or len(horarios) >= 24:
              break
          ──────────────────────────────────────────────────────────────────
          Si ya vimos esta hora (dimos la vuelta completa) O si ya
          tenemos 24 horarios (límite de seguridad), rompe el bucle.

          vistos.add(hora_str)
          horarios.append(hora_str)
          hora_actual += timedelta(hours=frecuencia)
          ──────────────────────────────────────────────────────────────────
          Agrega la hora actual a las dos colecciones.
          Luego suma la frecuencia de horas al objeto de hora.
          += con timedelta es como hacer: hora_actual = hora_actual + timedelta(hours=8)

      return horarios
      ────────────────────────────────────────────────────────────────────────
      Devuelve la lista completa de horarios calculados.

  def bucle_recordatorios():
  ──────────────────────────────────────────────────────────────────────────────
  Esta función corre en el HILO DE SEGUNDO PLANO.
  Mientras el menú principal está visible, esta función está
  corriendo al mismo tiempo en un proceso paralelo.

      global recordatorio_activo
      ────────────────────────────────────────────────────────────────────────
      Necesita acceder a la variable global para poder leerla y modificarla.

      while recordatorio_activo:
      ────────────────────────────────────────────────────────────────────────
      El bucle continúa SOLO MIENTRAS el interruptor sea True.
      Cuando alguien llame a detener_recordatorios() y ponga
      recordatorio_activo = False, este bucle termina en la próxima
      vuelta.

          verificar_recordatorios()
          ──────────────────────────────────────────────────────────────────
          Revisa si toca algún medicamento AHORA MISMO.

          for _ in range(INTERVALO_REVISION):
              if not recordatorio_activo:
                  break
              time.sleep(1)
          ──────────────────────────────────────────────────────────────────
          Este es un patrón especial para hilos. En vez de time.sleep(30),
          hacemos 30 pausas de 1 segundo. ¿Por qué?

          Si hiciéramos time.sleep(30) directamente, el hilo quedaría
          CONGELADO 30 segundos sin poder responder a nada.
          Con sleep(1) x 30, cada segundo verifica si debe detenerse.
          El _ en "for _" es convención: indica que el contador no se usa.


  def iniciar_recordatorios():
  ──────────────────────────────────────────────────────────────────────────────
      global hilo_recordatorio, recordatorio_activo
      ────────────────────────────────────────────────────────────────────────
      Necesita modificar ambas variables globales.

      if recordatorio_activo and hilo_recordatorio and hilo_recordatorio.is_alive():
      ────────────────────────────────────────────────────────────────────────
      Condición triple con evaluación en CORTO CIRCUITO:
      Python evalúa de izquierda a derecha y para en cuanto
      uno sea False (no necesita evaluar los demás).

      1. recordatorio_activo   → ¿está encendido el interruptor?
      2. hilo_recordatorio     → ¿existe el objeto de hilo (no es None)?
      3. .is_alive()           → ¿sigue corriendo ese hilo?

      Si los tres son True, los recordatorios ya están activos.

      recordatorio_activo = True
      hilo_recordatorio = threading.Thread(
          target=bucle_recordatorios, daemon=True
      )
      hilo_recordatorio.start()
      ────────────────────────────────────────────────────────────────────────
      1. Enciende el interruptor.
      2. Crea un HILO nuevo que ejecutará bucle_recordatorios().
         target=bucle_recordatorios → función que correrá en el hilo.
         daemon=True → si el programa principal cierra, este hilo
                       muere automáticamente con él.
      3. .start() arranca el hilo. Desde este momento, bucle_recordatorios()
         corre EN PARALELO al menú principal.


  def detener_recordatorios():

      en su próxima iteración del bucle y se detendrá solo.
      No necesitamos "matar" el hilo a la fuerza.

  if __name__ == "__main__":
      main()
  ──────────────────────────────────────────────────────────────────────────────
  Esta es una de las líneas más importantes de cualquier programa Python.

  __name__ es una variable especial que Python asigna automáticamente.
  Cuando ejecutas directamente el archivo:
    python3 recordatorio_medicamentos.py
    → __name__ vale "__main__"
    → la condición es True → se llama a main() → el programa arranca

  Cuando OTRO archivo lo importa (como api.py que hace "import recordatorio_medicamentos"):
    → __name__ vale "recordatorio_medicamentos" (el nombre del módulo)
    → la condición es False → main() NO se llama → solo se cargan
      las funciones y variables sin ejecutar el menú

  Sin esta línea, al hacer "import recordatorio_medicamentos" en api.py,
  el menú se abriría solo en la terminal, lo cual no queremos.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1.  global          → permite modificar variables fuera de la función
  2.  try/except      → maneja errores sin explotar el programa
  3.  while True/break→ bucle que repite hasta que algo lo rompa
  4.  .get(k, default)→ acceso seguro a diccionarios con valor por defecto
  5.  any(gen)        → verifica si algún elemento cumple una condición
  6.  enumerate()     → recorre una lista con índice y valor al mismo tiempo
  7.  threading.Thread→ ejecuta dos cosas en paralelo
  8.  f-strings       → texto con variables: f"Hola {nombre}"
  9.  strptime/strftime→ convierte entre texto y objetos de hora
  10. __name__=="__main__" → protege el punto de entrada del programa
